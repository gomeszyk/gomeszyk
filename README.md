## 👨‍💻 Sobre mim

Sou **Gabriel Prado Gomes**, estudante de **Análise e Desenvolvimento de Sistemas (UNIP)** e de **Desenvolvimento Web no Instituto PROA**. Tenho experiência em suporte técnico e infraestrutura de TI e estou direcionando minha carreira para o **desenvolvimento Full Stack**.

Gosto de transformar conceitos de programação em exercícios e interfaces reais. Aqui compartilho projetos de estudo, práticas de HTML/CSS, JavaScript e React e minha evolução como desenvolvedor.

- 🎓 Formação: Análise e Desenvolvimento de Sistemas — UNIP

- 🛠️ Experiência: suporte técnico, atendimento a usuários e infraestrutura
